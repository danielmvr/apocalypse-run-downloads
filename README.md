# Apocalypse Run — APK de testes

Canal público de distribuição da alpha Android do Apocalypse Run.

## Baixar ou atualizar

[**Baixar o APK mais recente**](https://github.com/danielmvr/apocalypse-run-downloads/releases/download/alpha-debug-latest/app-debug.apk)

Este link permanece o mesmo a cada atualização. Não exige conta no GitHub.

Abra o link no Android e instale o APK baixado. Se o Android solicitar, permita a instalação pelo navegador usado. Para atualizar mantendo os dados, instale por cima da versão anterior; não desinstale o aplicativo.

Requer Android 8 ou posterior. O download é público; a participação na alpha online continua dependendo de convite individual fornecido pela administração. Não há atualização automática em segundo plano: abra novamente o link para baixar e instalar uma nova versão.

Confira versão, build e checksum na [release de testes](https://github.com/danielmvr/apocalypse-run-downloads/releases/tag/alpha-debug-latest). Este repositório contém somente informações de distribuição e binários; o código do jogo é mantido separadamente.
